USE CASE SPECIFICATION
2.1. Danh sách Tác nhân (Actors)
Guest (Khách vãng lai): Người dùng chưa đăng nhập, chỉ có quyền xem thông tin công khai.
User (Người dùng hệ thống): Tác nhân Cha (Abstract Actor) đại diện cho bất kỳ ai đã xác thực tài khoản thành công.
Customer (Khách hàng): Tác nhân con, đa kế thừa từ User (để dùng tài khoản) và Guest (để xem phim). Có quyền mua vé và đánh giá.
Employee (Nhân viên rạp): Tác nhân con, kế thừa từ User. Có quyền thao tác soát vé và bán đồ ăn tại quầy.
Manager (Quản lý rạp): 	Tác nhân con, kế thừa từ User. Điều hành hoạt động kinh doanh (Phim, lịch chiếu, nhân sự, khuyến mãi).
System Admin (Quản trị hệ thống): Tác nhân con, kế thừa từ User. Bảo trì nền tảng, quản lý phân quyền và cấu hình.
2.2. Chi tiết Use Case theo phân tầng kế thừa
Nhóm 1: Use Case của Guest (Khách chưa đăng nhập)
Register: Đăng ký tài khoản hệ thống.
View Movie List: Xem danh sách phim.
Mở rộng (<<extend>>): View Movie Detail (Xem chi tiết phim).
Mở rộng (<<extend>>): View Rating List (Xem đánh giá từ khách hàng khác).
Nhóm 2: Use Case của User (Tác nhân Cha - Đã đăng nhập)
(Mọi Actor con: Customer, Employee, Manager, System Admin đều mặc định sở hữu các chức năng này)
Login (Đăng nhập)
Mở rộng (<<extend>>): Forgot Password (Quên mật khẩu).
Logout (Đăng xuất)
Manage Profile (Quản lý hồ sơ)
Mở rộng (<<extend>>): Edit Profile (Cập nhật thông tin).
Mở rộng (<<extend>>): Change Password (Đổi mật khẩu).
Nhóm 3: Use Case của Customer (Khách hàng)
(Đa kế thừa toàn bộ Use Case của User và Guest)
Book Ticket (Đặt vé trực tuyến):
Bao gồm (<<include>>): Select Seat (Bắt buộc chọn ghế).
Bao gồm (<<include>>): Pay (Bắt buộc thanh toán).
Mở rộng (<<extend>>): Select Food (Chọn đồ ăn kèm).
Mở rộng (<<extend>>): Apply Promotion (Áp mã giảm giá).
View Booked Tickets (Xem lịch sử đặt vé):
Mở rộng (<<extend>>): Rate Movie (Chỉ áp dụng với vé đã xem).
Mở rộng (<<extend>>): View Feedback (Xem phản hồi).
Nhóm 4: Use Case của Employee (Nhân viên rạp)
(Kế thừa từ User)
Ticket Checking (Kiểm tra vé):
Mở rộng (<<extend>>): Scan QR / Check-in (Quét mã vé).
Mở rộng (<<extend>>): View Booking Ticket List (Xem danh sách vé).
Mở rộng (<<extend>>): Create Ticket (Bán vé offline tại quầy).
Manage Food (Quản lý quầy đồ ăn): Add, Edit, Delete, View Food List.
Room Checking: Kiểm tra trạng thái phòng chiếu.
Nhóm 5: Use Case của Manager (Quản lý rạp)
(Kế thừa từ User)
Manage Movie: Add, Edit, Delete Movie.
Manage Movie Schedule: Add, Edit, Delete Schedule.
Manage Promotion: Tạo, sửa, xóa, quản lý mã Voucher.
Manage Room: Add Room, Edit Room, Seat Management, Set VIP Seat.
Manage Employee: Thêm, sửa, vô hiệu hóa nhân viên.
View Ticket Statistic: Báo cáo doanh thu (vé + đồ ăn).
Nhóm 6: Use Case của System Admin (Quản trị hệ thống)
(Kế thừa từ User)
Manage User Accounts: Assign Roles (Cấp quyền), Block/Unblock Account.
Manage System Configuration: Cấu hình giao diện, policy web.
System Monitoring: View System Logs, Backup/Restore Database.
